# UX_PRINCIPLES

Este documento es uno de los que más valor puede aportar.

Definirá principios como:

La usuaria probablemente está nerviosa.
Cada pantalla debe mostrar una única acción principal.
No utilizar lenguaje alarmista.
Evitar colores que generen ansiedad.
Toda recomendación debe ser comprensible en menos de cinco segundos.
La aplicación debe poder utilizarse con una sola mano.
Funcionar completamente sin conexión.
Registrar automáticamente la información importante.
Mostrar siempre por qué se hace una recomendación.
